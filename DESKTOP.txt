Rosé Pine Moon desktop (Arch / EndeavourOS)

After cloning or pulling this repository, run as your normal user:
  ./setup-desktop.sh

Requires an existing i3 desktop, yay, and internet access. The script installs
rose-pine-gtk-theme-full (GTK themes and matching icons) and JetBrains Mono.
Sudo and AUR review prompts remain interactive. Theme assets stay out of Git.
Reruns install only missing packages and skip downloading an existing cursor
theme. Config links already pointing to this checkout are left in place.

Win+C opens qalc in a floating Ghostty terminal, or focuses it if already open.
Results update as you type (autocalc is enabled on every launch). Press Enter
to keep a result in the session. Select text and use Ctrl+Shift+C
to copy; Ctrl+Shift+V pastes. The calculator stays open when focus moves away.
Type quit to close it. setup-desktop.sh installs libqalculate (qalc) and xclip
when missing.

Win+/ opens fuzzy file search across the home directory. Enter opens the selected
file in its default application. Hidden and ignored files, dependency caches
and common build directories are excluded. Searches match filenames and paths,
not file contents. Setup installs fd and xdg-utils only when missing.

Win+D reuses an existing Vesktop, Discord or pavucontrol window when launched
without arguments, switching to its workspace. Other applications and launches
with file/URL arguments keep their normal behavior.

Zsh directory jumping: z NAME jumps to a previously visited directory;
zi NAME opens a fuzzy picker. Setup installs zoxide and fzf only when missing
and appends guarded initialization to .zshrc only once, preserving its contents.
Open a new terminal after setup. Normal cd continues to work and teaches zoxide.

Links desktop, rofi, i3, ghostty, and zathura configs from this checkout. Existing files
are backed up under ~/.local/state/desktop-setup/. Review machine-specific
monitor, application and home-directory bindings in the full i3 config before
using it on another computer. Restart open GTK applications after setup.

GTK: rose-pine-moon-gtk. Icons: rose-pine-moon-icons. GTK4 imports the packaged
Moon CSS. GTK's prefer-dark flag is off as required by the upstream theme;
Moon itself is still a dark palette. Ghostty uses built-in Rose Pine Moon.
Rofi retains the small text-only layout. Bar stays at the top, with system
stats and 14px right padding. Reload Ghostty using Ctrl+Shift+comma.

Reviewed 2026-10-27: AUR 2.2.0-3 downloads versioned upstream releases with
SHA-256 verification and packages GTK3, GTK4 and icons. No upstream installer
script is executed. Review future AUR recipe changes through yay.

Zathura uses a local Moon palette adaptation; no official Zathura port was
found. Recolored reading mode is enabled; Ctrl+R toggles original colors.

Picom adds 6px rounded corners to regular windows; i3 uses 4px gaps.
The bar and full-screen windows stay square; Rofi draws its own 8px corners. Picom starts with i3.

Window borders are 2px, with Rosé Pine love (#eb6f92) marking focus, matching Firefox and the selected workspace.

Firefox: use the Rosé Pine Dark Theme add-on (main palette). Installation URL
and migration instructions are in firefox/README.txt. The previous custom CSS
is disabled by firefox/install.py; restart Firefox after migration.

Ghostty and i3bar backgrounds use 98% opacity (2% transparency). Picom must run.
Workspace highlights have square corners because i3bar cannot round them.
Pink marks the focused workspace; cyan marks a workspace visible on another monitor.
Notifications use compact padding, 8px corners, and stay on monitor 0.

The setup renders wallpapers/bipboplabs.svg to ~/.local/share/wallpapers/bipboplabs.png
and i3 restores it on login. The Python generator uses explicit dot-matrix glyphs,
with no AI assets or font dependencies. Source and SVG are stored in Git.

To include Firefox preferences during desktop setup, first launch Firefox once:
  FIREFOX_PROFILE=dev-edition-default ./setup-desktop.sh
Use default-release for regular Firefox, or the name listed in about:profiles.
Then install the linked Rosé Pine Dark Theme add-on and restart Firefox.
Firefox's own add-on confirmation is required; browser profile data stays local.

Existing app dependencies: i3/i3blocks, Ghostty, Rofi, PCManFM, Zathura and a PDF
backend. The cursor theme is BreezeX-RosePine-Linux at 24px. Some inherited keybindings require local scripts (sttop) and apps;
review them for the target machine. snixembed is optional for tray bridging.

Corner scale (Apple-inspired, not exact macOS metrics):
  windows: 6px (Picom; larger radii visibly clip i3 pixel borders)
  popovers, Rofi and notifications: 8px (app-drawn where supported)
  GTK controls and Firefox tabs/fields: 4px
Nested shapes should use max(outer radius - inset, 0); Rofi rows remain square
because their inset is larger than the popup radius. Fullscreen and i3bar stay
square. Picom provides circular arcs, not Apple's continuous corner curves.
GTK apps and Firefox need restarting after radius changes.
Reference: https://developer.apple.com/documentation/swiftui/edge/corner/style/concentric

Window-border limitation: https://github.com/yshui/picom/issues/1400

Mouse side buttons 8/9 switch previous/next existing workspace on the current
monitor while over windows/borders, replacing application Back/Forward.

Picom 13 holds hidden normal windows for 16ms, then removes them in one step.
This mitigates wallpaper flashing during fast workspace switches without a
gradual fade. Confirmed on this setup with mouse and keyboard navigation.
Reference: https://github.com/yshui/picom/issues/16

Rosé Pine cursors: setup-desktop.sh runs setup-cursor.sh, which downloads the
pinned official v1.1.0 Linux archive and verifies its SHA-256 before installing
under ~/.local/share/icons. Assets stay out of Git; no sudo is required for the
cursor install. GTK2/3/4, Xsettings, Xresources and the Xcursor fallback agree on
BreezeX-RosePine-Linux, size 24. Older apps may require restarting or a new login.
Source: https://github.com/rose-pine/cursors

Win+O keeps the blurred screenshot lock screen. Install i3lock-color with
`yay -S i3lock-color` for Rosé Pine Moon unlock-ring and feedback colors.
It replaces the stock i3lock package; the script also supports stock i3lock
with its original indicator colors. Source: https://github.com/Raymo111/i3lock-color
With i3lock-color, a centered iris ring stays visible: rose arcs react to typing,
gold to backspace, foam to verification and love to errors. The ring radius is
96px with a 5px stroke; the blur and JetBrains Mono text remain.
Picom 13 eases the lock screen in over 0.5s and out over 0.22s.

Vesktop: setup-desktop.sh installs the pinned Rosé Pine Moon CSS through
vesktop/install.py. Enable Custom CSS in Vencord once; updates then reload live.
The installer preserves unrelated QuickCSS and leaves plugin/account settings
local. See vesktop/README.txt for source and standalone setup instructions.
